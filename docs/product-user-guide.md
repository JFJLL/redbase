# RedBase 产品使用说明

RedBase 是一款面向品牌方、小红书运营团队和内容策划人员的 AI 内容运营工具。它围绕“品牌档案 -> 热点趋势分析 -> 内容选题 -> 内容图片生成 -> 历史沉淀”组织工作流，帮助运营人员把品牌资料转化为可执行的小红书内容方向。

本文档介绍如何启动系统、使用前台工作台，以及如何使用管理后台查看用户和额度消耗。

## 1. 产品能力概览

RedBase 当前包含两个入口：

- 用户工作台：`http://127.0.0.1:3013`
- 管理后台：`http://127.0.0.1:3013/admin`

用户工作台提供以下能力：

- 账号注册与登录
- 品牌档案创建与管理
- AI 热点趋势分析
- 基于趋势生成小红书内容选题
- 重新生成选题
- 一键生成朋友圈图
- 一键生成公众号长图
- 一键生成小红书 4 页组图
- 查看历史生成内容

管理后台提供以下能力：

- 查看用户数量、品牌数量、生成次数、总消耗使用额度
- 查看每个用户当前额度、累计消耗、生成次数和品牌数
- 手动给用户增加额度
- 查看额度消耗流水
- 查看用户生成过的内容、图片、文案和生成详情

## 2. 启动与访问

### 2.1 安装依赖

在项目根目录执行：

```bash
npm install
```

### 2.2 配置模型服务

生产和本地运行都优先使用环境变量，不要把真实 API Key 写入仓库文件。

PowerShell 示例：

```powershell
$env:TEXT_API_STYLE = "google"
$env:TEXT_MODEL = "gemini-3.1-flash-lite-preview"
$env:TEXT_BASE_URL = "https://api.im-red-magic.cn"
$env:TEXT_API_KEY = "<your-text-api-key>"
$env:IMAGE_API_KEY = "<your-image-api-key>"
$env:ADMIN_PHONES = "13800000000"
$env:ASSET_SIGNING_SECRET = "<long-random-string>"
npm start
```

常用环境变量：

- `TEXT_API_STYLE`：文本模型接口类型，默认 `google`
- `TEXT_MODEL`：文本模型名，默认 `gemini-3.1-flash-lite-preview`
- `TEXT_BASE_URL`：Google 风格文本接口地址
- `TEXT_OPENAI_BASE_URL`：OpenAI 兼容接口地址
- `TEXT_ANTHROPIC_BASE_URL`：Anthropic 兼容接口地址
- `TEXT_API_KEY`：文本模型 API Key
- `TEXT_SEARCH_ENABLED`：是否启用搜索，默认 `true`
- `IMAGE_BASE_URL`：图片生成接口地址
- `IMAGE_EDIT_BASE_URL`：图片编辑接口地址
- `IMAGE_UPLOAD_BASE_URL`：图片上传接口地址
- `IMAGE_MODEL`：图片模型名，默认 `gpt-image-2`
- `IMAGE_API_KEY`：图片模型 API Key
- `IMAGE_ASPECT_RATIO`、`IMAGE_RESOLUTION`、`IMAGE_QUALITY`、`IMAGE_COUNT`：图片参数
- `ADMIN_PHONES`：允许进入管理后台的管理员手机号，多个用英文逗号分隔
- `CORS_ORIGINS`：允许跨域访问的前端来源，多个用英文逗号分隔；同源本地访问不需要配置
- `ASSET_SIGNING_SECRET`：图片/资产签名 URL 的 HMAC 密钥；生产环境建议配置长随机字符串，未配置时会使用进程内临时密钥

如果配置了 `ADMIN_PHONES`，只有列表中的手机号可以进入管理后台。修改环境变量后需要重启服务才能生效。

### 2.3 启动服务

默认端口是 `3013`：

```bash
npm start
```

如果需要临时指定端口，例如 `3023`：

```powershell
$env:PORT="3023"
npm start
```

访问地址会变成：

```text
http://127.0.0.1:3023
http://127.0.0.1:3023/admin
```

### 2.4 健康检查

打开：

```text
http://127.0.0.1:3013/api/health
```

如果返回 `ok: true`，说明服务已启动。健康检查也会显示文本模型和图片模型是否已配置。

## 3. 账号注册与登录

打开用户工作台后，点击“登录 / 注册”。

注册时需要填写：

- 账号类型：客户或易美
- 手机号
- 昵称
- 登录密码
- 如果选择易美账号，需要选择部门

不同账号类型的默认额度不同：

- 易美账号：默认 50 额度
- 客户账号：默认 5 额度

登录后会进入 RedBase 工作台，左侧导航包含：

- 首页
- 品牌档案
- 趋势分析
- 内容选题
- 历史生成

同一个账号可以同时登录用户工作台和管理后台，两个页面不会互相顶掉登录状态。

登录状态由服务端 HttpOnly Cookie 保存，前端不会把 session token 放到 URL 或 localStorage。普通 API 请求会自动携带同源 Cookie；历史图片、品牌 Logo 和产品图等受保护资源通过短时签名 URL 访问。

## 4. 用户工作台使用流程

### 4.1 创建品牌档案

进入“品牌档案”，点击“新增品牌”。

需要填写：

- 品牌名称
- 行业分类
- 目标受众
- 品牌介绍
- 产品介绍
- 品牌资料库
- 运营目标

建议在“品牌资料库”中补充更具体的信息，例如：

- 品牌故事
- 核心卖点
- 成分、材质或参数说明
- 产品使用场景
- 视觉风格
- 竞品差异
- 禁用表达或内容边界

品牌资料越具体，趋势分析和内容生成越贴近品牌。

### 4.2 AI 热点趋势分析

进入“趋势分析”，选择品牌后点击“开始 AI 热点分析”。

该操作会消耗 1 额度。

系统会基于品牌档案生成三类趋势：

- 全网热点指数：跨平台高讨论度内容方向
- 品类热点指数：品牌所属行业或品类内的内容机会
- 新闻热点趋势：近期新闻、行业动态、社会议题或消费趋势中的可内容化机会

每类趋势会包含：

- 趋势标题
- 分类
- 摘要
- 热度分
- 标签
- 适配品牌的原因
- 对应内容选题

趋势分析完成后，系统会保存历史分析记录，可以在“历史分析”中回看并恢复查看。

### 4.3 查看与生成内容选题

进入“内容选题”，系统会展示当前品牌和趋势下的选题建议。

每个选题包含：

- 内容摘要
- 切入角度
- 品牌结合方式
- 面向人群
- 开头钩子
- 标签

如果想调整选题方向，可以在“自定义补充提示词”中填写额外要求，然后点击“重新生成选题”。

重新生成选题会消耗 1 额度。

常见补充提示词示例：

- 希望标题更克制，不要太营销化
- 内容更偏高端质感
- 强调新品上市
- 避免低价促销表达
- 更适合 25-35 岁都市女性
- 更像真实小红书博主笔记

### 4.4 上传产品图参考

在每个选题卡片中，可以上传产品图作为生图参考。

上传后需要勾选“使用该产品图生成图片”，系统才会在生成图片时把它作为参考图传给图片模型。

适合上传的图片包括：

- 产品包装图
- 产品实拍图
- 品牌物料图
- 视觉参考图

### 4.5 生成朋友圈图

在选题卡片中点击“一键朋友圈图”。

该操作会消耗 1 额度。

系统会生成：

- 朋友圈配图
- 朋友圈文案
- 视觉方向
- 风格说明
- 构图建议
- 生图 Prompt
- 使用的模型信息

图片生成通常需要几十秒，页面会显示任务等待状态。

### 4.6 生成公众号长图

在选题卡片中点击“一键公众号长图”。

该操作会消耗 1 额度。

系统会生成：

- 公众号长图
- 发布标题
- 文章导语
- 内容结构
- 长图定位
- CTA 建议
- 长图生图 Prompt

该能力适合把热点选题整理成更完整、更适合长阅读的公众号内容资产。

### 4.7 生成小红书组图

在选题卡片中点击“一键小红书组图”。

该操作会消耗 4 额度。

系统会生成 4 张连续组图，并配套：

- 发布标题
- 发布文案
- 组图说明
- 每一页的标题
- 每一页的文案
- 每一页的生图 Prompt

小红书组图必须等待 4 张图片全部生成完成后，才会写入历史生成记录。

## 5. 历史生成

进入“历史生成”可以查看当前账号已经生成过的内容资产。

历史记录包括：

- 生成类型：朋友圈图、公众号长图、小红书组图
- 生成时间
- 品牌名称
- 趋势标题
- 选题标题
- 生成文案
- 图片预览

该页面适合用于回看、复用和沉淀已经生成过的内容。

## 6. 使用额度说明

系统使用“额度”控制 AI 操作消耗。

当前默认消耗规则：

| 操作 | 消耗额度 |
| --- | ---: |
| AI 热点趋势分析 | 1 |
| 重新生成选题 | 1 |
| 朋友圈图生成 | 1 |
| 公众号长图生成 | 1 |
| 小红书组图生成 | 4 |

如果用户额度不足，系统会阻止本次操作，并提示当前剩余额度和本次所需额度。

注意：管理后台中展示的“使用额度”是系统内扣减额度，不等同于模型供应商返回的真实 token usage。

## 7. 管理后台使用说明

管理后台入口：

```text
http://127.0.0.1:3013/admin
```

如果使用临时端口，例如 `3023`：

```text
http://127.0.0.1:3023/admin
```

### 7.1 管理员权限

管理员手机号通过 `ADMIN_PHONES` 环境变量配置：

```powershell
$env:ADMIN_PHONES = "13800000000,13900000000"
npm start
```

修改配置后必须重启服务。

如果已经配置 `admin.phones`，不在列表中的账号无法进入管理后台。

### 7.2 查看总览数据

后台顶部展示：

- 用户数
- 品牌数
- 生成次数
- 总消耗使用额度
- 当前总额度

这些数据来自本地 SQLite 数据库 `data/redbase.sqlite`。

### 7.3 用户管理与手动加额度

在“用户管理”中可以查看：

- 用户昵称和手机号
- 账号类型
- 当前额度
- 总消耗使用额度
- 已加额度
- 生成次数
- 品牌数
- 最近活跃时间

给用户加额度时：

1. 选择用户
2. 输入增加额度
3. 填写备注
4. 点击“确认加额度”

加额度操作会写入消耗流水，便于后续追踪。

### 7.4 查看消耗流水

“消耗流水”记录：

- 操作时间
- 用户
- 动作类型
- 使用额度变化
- 关联品牌、趋势或生成内容
- 管理员加额度操作人

可以按用户筛选。

### 7.5 查看生成内容

“生成内容”展示所有用户生成过的内容。

每条记录会展示：

- 生成类型
- 本次生成消耗的使用额度
- 用户
- 品牌
- 生成时间
- 文案摘要
- 图片预览

点击“查看内容详情”后，可以查看：

- 用户、品牌、趋势、选题
- 本次生成消耗
- 生成图片
- 朋友圈文案、公众号内容或小红书组图内容
- 完整 payload

## 8. 数据保存位置

系统数据保存在：

```text
data/redbase.sqlite
```

其中包含：

- 用户
- 登录会话
- 品牌档案
- 趋势分析
- 内容选题
- 生成历史
- 额度流水

如果需要迁移或备份数据，优先备份该 SQLite 文件。

### 8.1 数据访问实现

当前主要业务写路径通过 `src/server/db/repositories/` 直接操作 SQLite 行，覆盖用户、会话、品牌、趋势、选题、历史生成、产品图、图片任务和积分流水。管理后台总览仍保留兼容读取，用于聚合展示；普通用户 CRUD、趋势、图片任务、产品图和积分流水不再通过整库快照写回。

### 8.2 维护烟测

基础代码检查：

```bash
npm run check
```

运行中的本地服务可以执行 API 烟测：

```bash
npm run smoke:api
```

默认烟测会完成健康检查、Cookie 登录、品牌创建/删除和产品图上传/删除，不调用真实 AI 服务。如果要验证真实趋势分析链路：

```powershell
$env:RUN_REAL_AI = "1"
npm run smoke:api
Remove-Item Env:RUN_REAL_AI
```

烟测变量：

- `SMOKE_BASE_URL`：服务地址，默认 `http://127.0.0.1:3013`
- `SMOKE_PHONE` / `SMOKE_PASSWORD`：登录账号，默认本地种子账号

## 9. 常见问题

### 9.1 修改管理员手机号后为什么没有生效？

环境变量只在服务启动时读取。修改后需要重启服务。

如果使用 PowerShell 启动：

```powershell
npm start
```

如果指定了端口：

```powershell
$env:PORT="3023"
npm start
```

### 9.2 为什么我看到端口上有多个连接？

查看端口时，只有 `Listen` 状态是真正的服务进程。

`FinWait2`、`TimeWait` 通常是浏览器或接口请求结束后的连接残留，不表示多个服务正在运行。

### 9.3 如何关闭指定端口的本地服务？

以 `3023` 端口为例：

```powershell
$pid = (Get-NetTCPConnection -LocalPort 3023 -State Listen).OwningProcess
Stop-Process -Id $pid -Force
```

确认是否关闭：

```powershell
Get-NetTCPConnection -LocalPort 3023 -State Listen
```

没有输出表示已关闭。

### 9.4 为什么生成图片需要等待？

图片生成走外部图片模型服务。提交任务后需要等待服务生成图片并返回结果，通常需要几十秒。

### 9.5 历史数据里的使用额度是真实模型 token 吗？

不是。当前系统记录的是 RedBase 内部使用额度。它用于统计和控制用户可用次数，不等同于文本模型或图片模型供应商的真实 token usage。

## 10. 推荐使用流程

日常运营建议按以下顺序使用：

1. 注册或登录账号
2. 新增品牌档案
3. 补充完整品牌资料库
4. 发起 AI 热点趋势分析
5. 在趋势中选择适合品牌的方向
6. 查看内容选题
7. 用补充提示词微调选题
8. 上传产品图参考
9. 生成朋友圈图、公众号长图或小红书组图
10. 在历史生成中回看和复用内容
11. 管理员在后台查看额度消耗并按需加额度

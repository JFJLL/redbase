# RedBase 模型调用与成本估算

本文按当前代码重新估算 RedBase 各环节的模型调用、token 消耗和单次成本。金额默认用美元，同时按 `1 USD = 6.802 CNY` 换算成人民币。汇率只用于预算估算，实际结算以支付渠道和中转站账单为准。

- 图片生成模型：`openai/gpt-image-2/text-to-image`
- 图片编辑模型：`openai/gpt-image-2/edit`
- 图片模型成本：按当前约定统一按 `$0.06/次` 计算。
- Gemini 官方价格来源：本次对话中提供的 Google AI Studio 定价截图。
- 汇率参考：[Investing.com USD/CNY](https://www.investing.com/currencies/usd-cny)，取近似值 `1 USD = 6.802 CNY`。
- 文本 token 测量：使用 Gemini `countTokens` 接口测输入 token；输出 token 使用小快克当前数据库里的最新生成结果样本测量。
- 样本品牌：`小快克`，品牌 ID `28`。

## 当前调用链

当前趋势分析已经按单个维度生成：用户选择一个 bucket 后，RedBase 调用一次文本模型，直接输出该 bucket 的 10 条趋势、20 个选题和每个选题的完整 `contentAssets`。如果模型返回结构不完整，代码会再走一次 strict retry，因此异常情况下文本成本可能接近翻倍。

小红书热点话题 bucket 使用 Pgy 小红书热门证据，不启用 Google Search。其他 5 个 bucket 会启用 `google_search`，如果超过 Gemini 免费 grounding 额度，需要额外按 grounded query 收费。

## 结论

按当前代码，小快克单个趋势维度分析大约消耗 `$0.05-$0.057`，约 `¥0.34-¥0.39`；平均约 `$0.0528`，`¥0.3588`。如果用户把 6 个趋势维度全部生成一遍，文本模型成本约 `$0.3165`，`¥2.1530`；若 5 个搜索型 bucket 都超过 Search grounding 免费额度，约 `$0.3865`，`¥2.6292`。

现在成本主要来自“单次 bucket 输出内容较完整”，而不是多阶段批量补齐。图片生成成本更稳定：单张约 `$0.06`，`¥0.4081`，小红书 4 张组图约 `$0.24`，`¥1.6325`。

如果按当前产品里的 `1 积分 = 1 次主要操作` 来理解，单个积分背后的模型成本大致是：

- 每个趋势单次生成 10 个话题 + 20 个内容选题框架，平均约 `¥0.35`；小红书热点话题约 `¥0.39`。
- 单个话题重新生成 2 个详细选题，约 `¥0.046`，可按 `¥0.042-¥0.046` 预算。
- 一张图片生成，约 `¥0.408`。

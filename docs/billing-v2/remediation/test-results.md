## 3. 验证范围与支付环境声明

1. **已验证部分**：
   - 本地完整的数据结构、增量数据库迁移、账本批次管理、FIFO 扣减算法、不可变报价引擎、订单状态机与履约重试。
   - 真实浏览器渲染、样式还原度、交互流程、弹窗焦点与键盘 Esc 操作。
   - 隔离 SQLite 数据库的多进程文件级竞争（WAL 模式并发安全）。
2. **测试环境与真实渠道边界**：
   - 本地端到端采用隔离配置的测试环境与测试 provider（`fake` 模式模拟支付宝与微信异步通知），未连接真实银行/商户生产网关。
   - 真实微信商户号公钥证书与支付宝真实公钥未在本地环境发起实际微额扣款，该部分需在线上灰度发布时接入外网异步回调 URL 后进行生产微额对账。

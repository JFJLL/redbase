Break `src/server/api/helpers.js` into responsibility-focused modules while preserving every exported helper name.

- [x] Extract admin view builders to `src/server/api/admin-views.js`.

- [x] Replace `helpers.js` with a facade that re-exports all focused modules.
- [x] Add new modules to `npm run check`.
- [x] Run check, tests, API smoke, browser login, and review.

- [x] Existing tests pass through `npm test`.

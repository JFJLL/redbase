# Plan 13-01: Add History Search And Filters

## Goal

Users can search history generation records and filter by brand, type, and created date range.

## Tasks

- [x] Add SQL-backed generation search in `generation-repository.js`.
- [x] Parse `/api/history` query parameters in `history-routes.js`.
- [x] Add history page filter controls and query-backed reload behavior.
- [x] Add focused regression tests for repository filtering and query parsing.
- [x] Run syntax checks, tests, authenticated API validation, real browser login, and review.

## Acceptance Criteria

- [x] `/api/history?q=...` searches card title, summary, trend title, idea title, and brand name.
- [x] `/api/history?brandId=...` and `/api/history?type=...` narrow results.
- [x] `/api/history?from=YYYY-MM-DD&to=YYYY-MM-DD` includes the selected days.
- [x] History page filters reload the list without requiring a full page refresh.
- [x] Empty filters preserve the original unfiltered history behavior.
